# File Naming — React & Next.js

Two rules:
- **React component files → PascalCase**
- **Everything else → camelCase**

---

## The rules

| File type | Format | Examples |
|-----------|--------|---------|
| React component | `PascalCase.tsx` | `ChatView.tsx`, `Avatar.tsx`, `AppSidebar.tsx` |
| React component styles | `PascalCase.module.scss` | `ChatView.module.scss`, `AppSidebar.module.scss` |
| Hook | `camelCase.ts` | `useAppState.ts`, `useChatRoom.ts`, `useIsMobile.ts` |
| Lib / utility / helper | `camelCase.ts` | `api.ts`, `adapters.ts`, `queryClient.ts`, `navigate.ts` |
| Type definitions | `camelCase.ts` | `types.ts`, `chatTypes.ts` |
| Constants | `camelCase.ts` | `constants.ts`, `routes.ts` |
| Test file | mirrors source | `ChatView.test.tsx`, `useIsMobile.test.ts` |

**How to tell if a file is a "component":** it exports a function whose name starts with a capital letter and returns JSX.

```tsx
// File: ChatView.tsx  ← PascalCase because this is a component
export function ChatView() { ... }

// File: useChatRoom.ts  ← camelCase because this is a hook
export function useChatRoom() { ... }

// File: adapters.ts  ← camelCase because this is a utility
export function roomToConversation() { ... }
```

## Next.js exceptions — framework-reserved files

These filenames are **required by Next.js** and must stay lowercase. Never rename them.

| File | Rule |
|------|------|
| `page.tsx` | Next.js page segment |
| `layout.tsx` | Next.js layout segment |
| `route.ts` | Next.js API route handler |
| `loading.tsx` | Next.js loading UI |
| `error.tsx` | Next.js error boundary |
| `not-found.tsx` | Next.js 404 page |
| `middleware.ts` | Next.js middleware |
| `global.css` | Global stylesheet entry |
| `next-env.d.ts` | Auto-generated by Next.js |

Route group folders and dynamic segment folders follow Next.js conventions and are lowercase:

```
app/
  (auth)/             ← route group — lowercase, parentheses
    login/
      page.tsx        ← Next.js reserved — lowercase
  (app)/
    [roomId]/         ← dynamic segment — lowercase, brackets
      page.tsx
  api/
    auth/
      login/
        route.ts      ← Next.js reserved — lowercase
```

## Folder names

Folders use camelCase, except Next.js route segments above.

```
components/           ← camelCase folder is fine for a flat group
  ChatView.tsx        ← PascalCase component file
  Avatar.tsx
hooks/
  useChatRoom.ts      ← camelCase hook file
lib/
  api/
    chatTypes.ts      ← camelCase lib file
    client.ts
```

---

## What NOT to use

| Pattern | Wrong | Correct |
|---------|-------|---------|
| camelCase component | `chatView.tsx` | `ChatView.tsx` |
| kebab-case component | `chat-view.tsx` | `ChatView.tsx` |
| PascalCase hook | `UseChatRoom.ts` | `useChatRoom.ts` |
| kebab-case hook | `use-async-action.ts` | `useAsyncAction.ts` |
| kebab-case lib | `chat-types.ts`, `auth-cookies.ts` | `chatTypes.ts`, `authCookies.ts` |

> **Legacy files**: `apps/shell/src/hooks/use-async-action.ts` and `use-form-state.ts` were renamed to `useAsyncAction.ts` and `useFormState.ts`. `apps/shell/src/lib/api/chat-types.ts` → `chatTypes.ts`. `apps/shell/src/lib/server/auth-cookies.ts` → `authCookies.ts`.
